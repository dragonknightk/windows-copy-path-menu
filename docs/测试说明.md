# 测试说明

本项目保留完整自动化测试源码。多选排序的验收标准是：输出与发起菜单的资源管理器视图排列一致，保留原选中对象；焦点位置不改变输出次序。

可通过以下命令一键执行全部自动化回归测试与发布包核验：

```powershell
.\scripts\test.ps1
```

## 源码回归测试

在项目根目录执行：

```powershell
.\scripts\build.ps1 -Target UnitTests
.\build\CopyPathMenuTests.exe
```

测试直接编译产品源码，使用真实文件系统对象组成 `IShellItemArray`，通过 `SetSelection`、`SetSite` 和 `Execute` 执行。视图服务由可控制的测试对象提供；剪贴板写入被截获到内存，避免测试污染用户剪贴板。

15 项用例覆盖：

- 焦点导致的选择数组循环位移按视图顺序恢复。
- 名称降序，以及与名称无关的视图排列。
- 未选中对象排除，原选择中的重复对象保留，视图重复对象不造成额外输出。
- 多选无调用方视图、空选择指针、原对象已不在视图中、枚举失败时，不清空或写入剪贴板。
- 单个包含中文和空格的路径无需视图即可复制。
- 非文件系统对象无法复制，不产生部分结果。
- COM 接口遵守同一 `IUnknown` 身份，站点可读取和清除。
- 无 `Selection` 时通过 `IExecuteCommand::SetDirectory` 复制当前目录路径。
- 命令行 `--copy` 对磁盘根目录 `"%V"` 展开产生的末尾转义双引号（如 `D:"`）归一化还原为 `D:\`，并拒绝非法内嵌双引号。

成功用例逐字符核对完整文本，包括 Unicode、单个 `CRLF` 分隔、不加双引号、末尾没有换行符。

## 安装升级测试

```powershell
.\tests\Install.Tests.ps1
```

测试兼容 Windows PowerShell 5.1 和 PowerShell 7。16 项用例覆盖首次安装、同版本重装、已登记旧版本升级，以及各种归属、哈希和内容不匹配的拒绝与事务回滚路径。

测试使用真实临时文件验证备份与恢复，通过内存注册表替身验证产品登记与回滚；不会修改实际产品注册表或安装目录。

## Explorer 真实菜单集成测试

前提：已安装本产品的菜单，打开一个 `C:\Windows` 资源管理器窗口；没有其他 `copy-path.exe` 进程正在处理操作。

```powershell
.\scripts\test-explorer.ps1 -CandidateExe .\build\copy-path.exe -Interactive
```

可追加 `-Case 1` 单独复测缺陷，或用 `-Case 2` 至 `-Case 6` 指定其他场景。也可以将 `-CandidateExe` 指向待发布的 `release\copy-path.exe`。

辅助程序保存窗口原选择、焦点、排序和分组，再逐项准备测试场景。每次打印 `READY` 后，须在 600 秒内对这个窗口中已选中的目录右键，点击本产品的“复制路径”。不要点击资源管理器功能区自带的“复制路径”。

辅助程序只准备场景、启动候选 COM 服务器并核验实际剪贴板；不手工注入站点或调用执行接口来替代真实菜单。激活后和菜单执行后都会核对候选进程的 PID、完整路径及存活状态，排除误测已安装版本。成功、失败或超时都会尝试恢复视图，并核验恢复结果。测试不替换已安装文件、不改动产品注册表。

完整场景：

1. 名称升序，焦点在 `DigitalLocker`。
2. 名称升序，焦点在 `Cursors`。
3. 名称升序，焦点在 `Downloaded Program Files`。
4. 名称降序。
5. 修改日期降序。
6. 单选。

每次输出必须与当前视图排列中原选中对象的完整路径逐字符一致。预期结果从真实视图读取，不另外按名称排序。

## 验证记录

- x64 发布程序和两种 C++ 测试程序构建通过。
- 源码回归测试：15 项通过。
- 安装升级测试：Windows PowerShell 5.1 和 PowerShell 7 各 16 项通过。
- 真实菜单集成测试：使用 `release\copy-path.exe`，名称升序、焦点在 `DigitalLocker` 的场景通过；剪贴板中 16 条完整路径逐字符匹配真实视图顺序，测试结束后原选择、焦点、排序和分组恢复并通过核验。
- 本机安装部署验证：`C:\Program Files\CopyPathMenu\copy-path.exe` 与发布程序逐字节一致，CLSID 与三个右键菜单项登记正确，通过已安装的 COM 登记激活程序支持 `IExecuteCommand`、`IObjectWithSelection` 与 `IObjectWithSite` 接口。
